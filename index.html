Einstellungen

Ort für das Wetter

YouTube-Suche im Dashboard

Damit die Suche direkt im Dashboard läuft, verlangt YouTube einen kostenlosen Schlüssel: console.cloud.google.com → Projekt anlegen → „YouTube Data API v3“ aktivieren → Anmeldedaten → API-Schlüssel erstellen → hier einfügen. Ohne Schlüssel kannst du Videos weiterhin per Link abspielen.

Tipps für das iPad

• Einstellungen → Anzeige & Helligkeit → Automatische Sperre → „Nie“, damit der Bildschirm an bleibt.
• In Safari: Teilen → „Zum Home-Bildschirm“, dann startet das Dashboard im Vollbild.
• Lautstärke über die Tasten am iPad regeln.
• Sender, Favoriten, Timer und Einkaufsliste werden nur auf diesem iPad gespeichert.
